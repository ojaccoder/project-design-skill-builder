# Source notes

These notes summarize publicly indexed references used to shape this builder. They are heuristics, not universal style rules.

For the eight primary sources on user scenarios, task effort, action priority, grouping, disclosure and feedback, see [interaction-layout.md](interaction-layout.md). Its GOV.UK, USWDS, NN/g and W3C WAI sources were read on 2026-10-29. That guide distinguishes source principles from project adaptations and does not treat click limits, button quotas or source-specific layouts as universal requirements.

- Xiaohongshu/RED skill “小红书高级图文视觉导演” emphasizes asking what the content is for, choosing a visual direction, planning hierarchy page by page, generating image prompts, and reviewing consistency. Adapted here as a discovery → direction → system → QA workflow.
- Xiaohongshu/RED skill “不做丑图” emphasizes analyzing the subject's material, proportion, color, texture, light, naming, copy, and layout before generating a finished visual. Adapted here as project-specific image direction and anti-template checks.
- Public discussions repeatedly warn that a skill alone cannot replace references, a design system, and screenshot QA. The builder therefore requires repository inspection, explicit assumptions, and verification rather than promising “anti-AI taste” automatically.

References: https://beav.pro/skills/xhs-visual-director-skill and https://beav.pro/skills/2351179894
